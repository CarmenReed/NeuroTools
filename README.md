# 🧰 NeuroTools

Neurodivergent-friendly tools for AI assistants.

## 📦 Tools

| Tool | What it does |
| --- | --- |
| [i-have-adhd](i-have-adhd/) | ADHD-friendly answers in Claude Code and Cursor |
| [token-saver](token-saver/) | Spend fewer tokens: read less, write less, do only the asked work |

## 🔌 Install (Claude Code)

```bash
claude plugin marketplace add CarmenReed/NeuroTools
```

Then install a tool by name, for example:

```bash
claude plugin install i-have-adhd@neurotools
```
